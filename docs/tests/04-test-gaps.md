# 04 — Непокрытые области

> **Дата среза:** 2026-11-01.
> **Назначение:** зафиксировать всё, что текущим набором тестов **не проверяется**, и сформулировать минимальный достижимый следующий тест для каждой строки. Реализация новых тестов **не начинается** (политика этой итерации — аудит, не разработка).
> **Связанные документы:** [`02-coverage-matrix.md`](02-coverage-matrix.md) — статусы, [`03-test-evidence.md`](03-test-evidence.md) — реальные результаты.

## Категории пробелов

- **Дефекты тестов:** тест, который должен быть, отсутствует; код есть.
- **Отсутствие тестов:** функционал реализован частично или полностью, но автоматической проверки нет.
- **Ограничения окружения:** нужен инструмент / сервис / секрет, которых нет.
- **Продуктовые ограничения:** функционал ещё не спроектирован / не реализован.
